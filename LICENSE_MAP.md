all files under one licence. Source-specific terms take precedence over this
summary.

## Required attribution

Where OpenStreetMap-derived geometry or a figure containing that geometry is
redistributed, include: `© OpenStreetMap contributors`, with a link to
<https://www.openstreetmap.org/copyright> and the Open Database License 1.0.

The LarNO article and public dataset must be cited using the bibliographic
information in `CITATION.cff` and the upstream project. MIKE is a commercial
model name and is used here only to identify the provenance of public reference
arrays; no MIKE software is included.

## Unresolved permission boundary

The public snapshot contains upstream LarNO arrays and a checkpoint so that the
reported calculations can be audited. The retained upstream material does not
include a complete standalone licence record for every data product. This
repository therefore does not assert that public hosting grants downstream
redistribution rights. Before creating a mirror, data release or commercial
derivative, obtain confirmation from the LarNO data authors or replace those
files with a documented download-and-hash workflow.
